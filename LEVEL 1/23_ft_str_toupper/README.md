==========================================================================================
Assignment name  : ft_str_toupper
Expected files   : ft_str_toupper.c
Allowed functions: (none)
------------------------------------------------------------------------------------------

Write a function that converts every lowercase letter in str to uppercase,
modifying it in place. Return str.

Your function must be declared as follows:

char	*ft_str_toupper(char *str);

Example:

ft_str_toupper("Hello World")  // modifies to "HELLO WORLD", returns pointer
ft_str_toupper("abc123")       // modifies to "ABC123"
ft_str_toupper("")             // returns ""
