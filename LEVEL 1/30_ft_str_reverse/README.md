Assignment name  : ft_str_reverse
Expected files   : ft_str_reverse.c
Allowed functions: (none)
------------------------------------------------------------------------------------------

Write a function that reverses a string in place. Return the modified string.

Your function must be declared as follows:

char	*ft_str_reverse(char *str);

Examples:

ft_str_reverse("hello")   // modifies to "olleh", returns pointer
ft_str_reverse("42")      // modifies to "24"
ft_str_reverse("a")       // remains "a"
ft_str_reverse("")        // remains ""
