Assignment name  : ft_print_params
Expected files   : ft_print_params.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that displays all its arguments, one per line, in order.

The program name (argv[0]) must NOT be displayed.

Example:

$>./ft_print_params hello world "42 school" | cat -e
hello$
world$
42 school$
$>./ft_print_params | cat -e
$>
