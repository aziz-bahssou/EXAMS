==========================================================================================
Assignment name  : ft_str_tolower
Expected files   : ft_str_tolower.c
Allowed functions: (none)
------------------------------------------------------------------------------------------

Write a function that converts every uppercase letter in str to lowercase,
modifying it in place. Return str.

Your function must be declared as follows:

char	*ft_str_tolower(char *str);

Example:

ft_str_tolower("Hello World")  // modifies to "hello world", returns pointer
ft_str_tolower("ABC123")       // modifies to "abc123"
