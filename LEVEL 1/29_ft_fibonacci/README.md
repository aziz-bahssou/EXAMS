Write a function that returns the nth element of the Fibonacci sequence.
The first element is at index 0 (fib(0) = 0, fib(1) = 1).
If the index is negative, return -1.

Your function must be declared as follows:

int	ft_fibonacci(int index);

Examples:

ft_fibonacci(0)    // returns 0
ft_fibonacci(1)    // returns 1
ft_fibonacci(5)    // returns 5
ft_fibonacci(10)   // returns 55
ft_fibonacci(-1)   // returns -1
