==========================================================================================
Assignment name  : ft_swap_chars
Expected files   : ft_swap_chars.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and swaps every pair of adjacent
characters, then displays the result followed by a newline.

If the string has an odd length, the last character stays in place.
If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_swap_chars "abcdef" | cat -e
badcfe$
$>./ft_swap_chars "hello" | cat -e
ehlol$
$>./ft_swap_chars "a" | cat -e
a$
$>./ft_swap_chars | cat -e
$
