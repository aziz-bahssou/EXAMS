==========================================================================================
Assignment name  : ft_count_words
Expected files   : ft_count_words.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and displays the number of words it
contains, followed by a newline. A word is a section of the string delimited
by spaces, tabs, or the start/end of the string.

If the number of arguments is not 1, display 0 followed by a newline.

Examples:

$>./ft_count_words "Hello World" | cat -e
2$
$>./ft_count_words "  one   two three  " | cat -e
3$
$>./ft_count_words "" | cat -e
0$
$>./ft_count_words | cat -e
0$
