Expected files   : ft_merge_sort.c
Allowed functions: malloc, free

Write a function that sorts an array of integers using the merge sort
algorithm.

The function modifies the array in place.

Your function must be declared as follows:

void	ft_merge_sort(int *tab, int size);

You must implement merge sort, not another sorting algorithm.

Example:

int tab[] = {5, 3, 8, 1, 2, 9, 4, 7, 6};
ft_merge_sort(tab, 9);
// tab is now {1, 2, 3, 4, 5, 6, 7, 8, 9}
