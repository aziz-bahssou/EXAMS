==========================================================================================
Assignment name  : ft_permutations
Expected files   : ft_permutations.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and displays all its unique permutations,
one per line, in lexicographic (alphabetical) order.

Duplicate characters in the input should NOT produce duplicate permutations.

If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_permutations "abc"
abc
acb
bac
bca
cab
cba
$>./ft_permutations "ab"
ab
ba
$>./ft_permutations "aab"
aab
aba
baa
