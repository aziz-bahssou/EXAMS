==========================================================================================
Assignment name  : ft_combinations
Expected files   : ft_combinations.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes two arguments: a string and a number k, and
displays all combinations of k characters chosen from the string, one per
line, in lexicographic order.

The characters in each combination must appear in the same relative order
as in the original string. No character may be used more than once per
combination.

If the arguments are invalid or k > string length, display only a newline.

Examples:

$>./ft_combinations "abcd" "2"
ab
ac
ad
bc
bd
cd
$>./ft_combinations "abc" "3"
abc
