==========================================================================================
Assignment name  : ft_balanced_parens
Expected files   : ft_balanced_parens.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a number n as argument and displays all possible
combinations of n pairs of well-formed (balanced) parentheses, one per line,
in lexicographic order.

If n is not a valid positive integer or the number of arguments is not 1,
display only a newline.

Examples:

$>./ft_balanced_parens "1"
()
$>./ft_balanced_parens "2"
(())
()()
$>./ft_balanced_parens "3"
((()))
(()())
(())()
()(())
()()()
