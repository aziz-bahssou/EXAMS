==========================================================================================
Assignment name  : ft_tower_of_hanoi
Expected files   : ft_tower_of_hanoi.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a number n and displays the sequence of moves
needed to solve the Tower of Hanoi puzzle with n disks.

The 3 pegs are named A, B, and C. All disks start on peg A and must be
moved to peg C.

Display each move as "X -> Y" followed by a newline, where X and Y are
peg names.

If n is not a valid positive integer or the number of arguments is not 1,
display only a newline.

Example:

$>./ft_tower_of_hanoi "3"
A -> C
A -> B
C -> B
A -> C
B -> A
B -> C
A -> C
