==========================================================================================
Assignment name  : ft_matrix_rotate
Expected files   : ft_matrix_rotate.c
Allowed functions: (none)
------------------------------------------------------------------------------------------

Write a function that rotates a square matrix 90 degrees clockwise, in place.

The rotation transforms the matrix so that:
- The first row becomes the last column
- The second row becomes the second-to-last column
- etc.

Your function must be declared as follows:

void	ft_matrix_rotate(int **matrix, int size);

Example (3x3):
Input:          Output:
1 2 3           7 4 1
4 5 6    ->     8 5 2
7 8 9           9 6 3
