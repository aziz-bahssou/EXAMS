==========================================================================================
Assignment name  : ft_snake_to_camel
Expected files   : ft_snake_to_camel.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a single string in snake_case format and displays
it in lowerCamelCase format, followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_snake_to_camel "hello_world" | cat -e
helloWorld$
$>./ft_snake_to_camel "this_is_a_test" | cat -e
thisIsATest$
$>./ft_snake_to_camel "already" | cat -e
already$
$>./ft_snake_to_camel | cat -e
$
