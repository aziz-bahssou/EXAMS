==========================================================================================
Assignment name  : ft_mirror_str
Expected files   : ft_mirror_str.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and displays it followed by its reverse,
separated by a pipe '|', followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_mirror_str "Hello" | cat -e
Hello|olleH$
$>./ft_mirror_str "42" | cat -e
42|24$
$>./ft_mirror_str "a" | cat -e
a|a$
$>./ft_mirror_str "" | cat -e
|$
$>./ft_mirror_str | cat -e
$
