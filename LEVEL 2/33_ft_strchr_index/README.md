Assignment name  : ft_strchr_index
Expected files   : ft_strchr_index.c
Allowed functions: (none)
------------------------------------------------------------------------------------------

Write a function that returns the index of the first occurrence of character c
in the string str. If the character is not found, return -1.

Your function must be declared as follows:

int	ft_strchr_index(char *str, char c);

Examples:

ft_strchr_index("hello", 'l')    // returns 2
ft_strchr_index("hello", 'h')    // returns 0
ft_strchr_index("hello", 'z')    // returns -1
ft_strchr_index("", 'a')         // returns -1
