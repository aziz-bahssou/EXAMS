==========================================================================================
Assignment name  : ft_nbrlen
Expected files   : ft_nbrlen.c
Allowed functions: (none)
------------------------------------------------------------------------------------------

Write a function that returns the number of digits needed to represent the
given integer (including the minus sign for negative numbers).

Your function must be declared as follows:

int	ft_nbrlen(int nb);

Examples:

ft_nbrlen(42)           // returns 2
ft_nbrlen(0)            // returns 1
ft_nbrlen(-42)          // returns 3
ft_nbrlen(2147483647)   // returns 10
ft_nbrlen(-2147483648)  // returns 11
