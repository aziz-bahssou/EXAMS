==========================================================================================
Assignment name  : ft_camel_to_snake
Expected files   : ft_camel_to_snake.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a single string in lowerCamelCase format and
displays it in snake_case format, followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_camel_to_snake "helloWorld" | cat -e
hello_world$
$>./ft_camel_to_snake "thisIsATest" | cat -e
this_is_a_test$
$>./ft_camel_to_snake "already" | cat -e
already$
$>./ft_camel_to_snake | cat -e
$
