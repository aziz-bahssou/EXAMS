==========================================================================================
Assignment name  : ft_remove_spaces
Expected files   : ft_remove_spaces.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and displays it with all spaces removed,
followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_remove_spaces "Hello World" | cat -e
HelloWorld$
$>./ft_remove_spaces "  a  b  c  " | cat -e
abc$
$>./ft_remove_spaces "no spaces" | cat -e
nospaces$
$>./ft_remove_spaces "" | cat -e
$
