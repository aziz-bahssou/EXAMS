Expected files   : ft_rev_array.c
Allowed functions: (none)
------------------------------------------------------------------------------------------

Write a function that reverses an array of integers in place.

Your function must be declared as follows:

void	ft_rev_array(int *tab, int size);

Examples:

int tab[] = {1, 2, 3, 4, 5};
ft_rev_array(tab, 5);
// tab is now {5, 4, 3, 2, 1}

int tab2[] = {42};
ft_rev_array(tab2, 1);
// tab2 is still {42}
