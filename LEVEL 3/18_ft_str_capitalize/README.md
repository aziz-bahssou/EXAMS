Modify str in place so the first letter of every word is uppercase and all other
letters are lowercase. A "word" is separated by any non-alphabetic character.
Return str.

(e.g. "hello world-42FOO" -> "Hello World-42Foo")

Your function must be declared as follows:

char	*ft_str_capitalize(char *str);
