==========================================================================================
Assignment name  : ft_word_search
Expected files   : ft_word_search.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a word as its first argument and a grid (each row
as a separate argument) and determines if the word can be found in the grid
by moving horizontally or vertically (no diagonal), without reusing the same
cell.

Display "Found" or "Not found", followed by a newline.

Examples:

$>./ft_word_search "HELLO" "HTXX" "EXXO" "LXLX" "XXXX"
Found
$>./ft_word_search "CAT" "ABC" "XAX" "XTX"
Found
$>./ft_word_search "DOG" "ABC" "DEF" "GHI"
Not found
