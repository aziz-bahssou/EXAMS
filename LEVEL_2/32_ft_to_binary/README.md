==========================================================================================
Assignment name  : ft_to_binary
Expected files   : ft_to_binary.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a single decimal number as argument and displays
its binary representation to the standard output, followed by a newline.

The input will always be a valid non-negative integer.
If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_to_binary "0" | cat -e
0$
$>./ft_to_binary "1" | cat -e
1$
$>./ft_to_binary "5" | cat -e
101$
$>./ft_to_binary "42" | cat -e
101010$
$>./ft_to_binary "255" | cat -e
11111111$
$>./ft_to_binary | cat -e
$
