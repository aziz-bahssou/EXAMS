==========================================================================================
Assignment name  : ft_print_even_idx
Expected files   : ft_print_even_idx.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and displays only the characters at even
indices (0, 2, 4, ...), followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_print_even_idx "abcdef" | cat -e
ace$
$>./ft_print_even_idx "Hello World!" | cat -e
HloWrd$
$>./ft_print_even_idx "" | cat -e
$
$>./ft_print_even_idx | cat -e
$
