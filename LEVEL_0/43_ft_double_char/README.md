==========================================================================================
Assignment name  : ft_double_char
Expected files   : ft_double_char.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and displays each character twice,
followed by a newline.

If the number of arguments is not 1, display only a newline.

Examples:

$>./ft_double_char "abc" | cat -e
aabbcc$
$>./ft_double_char "Hello" | cat -e
HHeelllloo$
$>./ft_double_char "" | cat -e
$
$>./ft_double_char | cat -e
$
