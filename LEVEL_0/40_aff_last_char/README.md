==========================================================================================
Assignment name  : aff_last_char
Expected files   : aff_last_char.c
Allowed functions: write
------------------------------------------------------------------------------------------

Write a program that takes a string and displays its last character, followed
by a newline.

If the number of arguments is not 1, or the string is empty, the program
displays only a newline.

Examples:

$>./aff_last_char "hello" | cat -e
o$
$>./aff_last_char "world!" | cat -e
!$
$>./aff_last_char "" | cat -e
$
$>./aff_last_char | cat -e
$
